# CursorTrailBar（macOS 鼠标轨迹 / 点击特效 / 快捷放大镜）

`CursorTrailBar` 是一个 **macOS 常驻型** 鼠标增强工具：  
- 启动时默认打开设置主界面；  
- 关闭设置窗口后继续后台运行；  
- 可选显示菜单栏图标（支持开关）。  

核心能力：
- 鼠标轨迹渲染（多种轨迹风格）；
- 鼠标点击特效（可按左/右/中键分别配置）；
- 按住快捷键触发的跟随放大镜（支持键盘/鼠标快捷键录制）；
- 日志输出与权限状态检测（便于排查问题）。

---

## 1. 当前功能概览

## 1.1 常规
- 开机启动开关（macOS 13+，建议将 `.app` 放在 `Applications`）；
- 菜单栏图标显示开关；
- 日志输出开关；
- 一键打开日志目录。

## 1.2 轨迹
- 轨迹总开关；
- 轨迹类型：
  - 双层霓虹
  - 渐隐丝带
  - 彩虹拖尾
  - 闪电轨迹
- 轨迹颜色逻辑（按类型动态显示）：
  - 双层霓虹：显示主色 + 辅色；
  - 彩虹拖尾：显示彩虹颜色组；
  - 其他轨迹：显示单一轨迹颜色；
- 轨迹粗细（px）；
- 轨迹长度（ms）；
- 特效类型：粒子火花 / 墨迹扩散 / 电弧闪点；
- 特效强度：关闭 / 低 / 中 / 高。

## 1.3 点击
- 点击特效总开关；
- 点击样式：实心脉冲 / 十字闪光；
- 点击效果半径（px）；
- 左键 / 右键 / 中键：
  - 独立开关
  - 独立颜色

## 1.4 放大镜
- 放大镜总开关；
- 放大时是否显示轨迹与特效；
- 放大镜半径（px）；
- 放大倍率（1.0x ~ 8.0x）；
- 边框粗细、边框颜色、阴影强度；
- 快捷键录制（支持键盘或鼠标键）；
- 权限状态检测 + 一键跳转到系统设置。

## 2. 运行方式（开发调试）

```bash
swift run
```

运行后会自动拉起设置窗口；关闭窗口后应用继续常驻。  
全局开关快捷键：

```text
⌃⌥⌘T
```

---

## 3. 打包为 `.app`

```bash
./scripts/build_app.sh
```

输出路径：

```bash
dist/CursorTrailBar.app
```

说明：
- `build_app.sh` 会生成 `Info.plist`、拷贝可执行文件、拷贝图标资源并尝试签名；
- 应用为 `LSUIElement=true`（无 Dock 图标，偏后台工具形态）。

---

## 4. 图标资源

### 4.1 重新生成 App 图标

```bash
./scripts/generate_app_icon.sh
```

生成文件：
- `assets/AppIcon.iconset`
- `assets/AppIcon.icns`

随后重新打包：

```bash
./scripts/build_app.sh
```

### 4.2 菜单栏图标

菜单栏图标为代码绘制的 **模板图标（Template Image）**，会自动适配系统主题：
- 系统深色模式 → 菜单栏图标自动浅色；
- 系统浅色模式 → 菜单栏图标自动深色。

---

## 5. 开机自启

项目支持两种方式：

### 5.1 应用内开关（推荐）
在设置界面「常规」中使用“开机启动”开关。

### 5.2 脚本方式

安装：

```bash
./scripts/install_launch_agent.sh
```

指定 app 路径安装：

```bash
./scripts/install_launch_agent.sh /Applications/CursorTrailBar.app
```

卸载：

```bash
./scripts/uninstall_launch_agent.sh
```

---

## 6. 权限说明与排查

放大镜与全局快捷能力依赖系统权限。若异常，请先检查设置界面的权限状态提示。

重点权限：
- 输入监控（影响全局快捷键/鼠标键触发）；
- 屏幕录制（影响放大镜抓屏）。

设置界面提供：
- `前往输入监控设置`
- `前往屏幕录制设置`

---

## 7. 日志与问题定位

在设置中开启“日志输出”后，可记录关键运行状态（如开关切换、快捷键触发、特效发射等）。

- 日志目录可通过设置界面的“打开日志文件夹”直接打开；
- 出现“效果不显示/权限相关问题”时，建议先开启日志后复现再查看。
